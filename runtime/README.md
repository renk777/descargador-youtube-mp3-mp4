# Motor JavaScript para compilar

Coloca aquí `deno.exe` de la distribución oficial de Deno para Windows x64.
La versión utilizada en v0.4.1 es Deno v2.9.8:
https://github.com/denoland/deno/releases/tag/v2.9.8

El SHA256 del ZIP original está en VERSION.txt; LICENSE.md contiene su licencia.
No se incluyen ejecutables de terceros en el repositorio Git. El paquete de la
release ya lleva el runtime incorporado en Descargador.exe.
